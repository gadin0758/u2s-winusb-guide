# 验证范围

## 现场原型已验证

- WinUSB mode 2 握手、重枚举、上游 FDL2 加载。
- 全部 GPT 分区及 SPL 备份，含超过 4 GB 的 userdata 和原始 NV 头部。
- 14 项系统目标刷写与读回校验。
- 原生 userdata 单分区擦除 ACK、三点空白抽查。
- 21 项保护分区与刷前快照一致，原生 reset ACK。
- 设备运行 B09，USB 网络恢复、基带初始化、5G 数据连接正常。

## 发布版离线验证

```powershell
python -m unittest discover -s tests -v
python -m compileall -q scripts tests
```

测试使用合成 GPT、临时文件和模拟 USB，覆盖帧校验、CRC 错误、物理范围、64 位请求、只读命令限制、磁盘哈希、写入完成消息、完整备份清单及重复擦除的前置阻止。PowerShell 文件还做语法解析检查。

2026-10-11 本地检查结果：27 项单元测试通过，Python 编译检查通过，4 个 PowerShell 文件语法解析通过。测试不需要连接设备，也不加载 USB DLL。

发布版把现场程序整理为参数化脚本，增加操作前保护数据比较、拒绝重复尝试和 pm_sys 保护。这些改动没有在已恢复的设备上再刷一次；**离线测试不能证明所有硬件、USB 时序、驱动组合或上游进程输出都兼容**。工具匹配不到 `FDL2 >` 或命令完成消息时会停止，不会继续自动重启。

文件 SHA-256 一致只能证明读取/保存内容一致，不能保证另一型号兼容。三点空白检查不是全分区擦除证明。GPT 相同也不能确认设备身份，所以写入前额外比较全部保护分区内容。

恢复 U2S 为人工逐步教程及驱动安装/导出助手；本案例最终保留 WinUSB，未把“WinUSB→U2S→再次刷写”作为完整硬件回归测试。
